### Prerequisites 📋

You'll need [VSCode](https://code.visualstudio.com/),[Git](https://git-scm.com/),[Node.js](https://nodejs.org/en/download/) installed on your computer.


---

## How To Use 🔧

In VSCode, Open the terminal(<kbd>Ctrl</kbd>+<kbd>\\</kbd> ) and clone the Repo.

```bash
# Clone this repository
$ git clone repo_url

# Go into the repository
$ cd repo_name

# Remove current origin repository
$ git remote remove origin

# Start Dev environment
$ npm run dev
```
