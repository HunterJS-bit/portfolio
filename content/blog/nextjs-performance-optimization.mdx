# Next.js Performance

Next.js is fast by default, but there are many ways to make it even faster.

## Image Optimization

Use the `next/image` component for:

- Automatic resizing
- WebP support
- Lazy loading

## Dynamic Imports

Reduce your bundle size by using `next/dynamic` for components that aren't needed on the initial load.
