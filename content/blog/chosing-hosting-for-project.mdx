I’d already tried [Cloudflare Pages](https://pages.cloudflare.com/), which works well for static sites. But these projects needed something more: a server where I could run a Node.js application, connect it to a database, and have more control over the environment.

Because I’m in Europe, I wanted to find a provider with servers in or near the region. I started by searching Google, then found my way to [Reddit’s VPS subreddit](https://www.reddit.com/r/vps/). Reading other users’ experiences helped me get a sense of which providers people commonly recommend. **Hetzner** and **OVHcloud** came up often, so I checked their offerings.

#### **OVHcloud**

I also looked at [OVHcloud](https://www.ovhcloud.com/), but its prices seemed a little higher than I expected, and I couldn’t find the kind of entry-level server I was looking for. I considered AWS as well, but it looked a bit expensive for what I wanted to do. These are hobby projects, so I’d prefer not to spend too much before I know whether they’ll be useful or attract users. If one of the projects really takes off, I can always move it to a larger cloud setup later.

### Why I Chose Euronodes—for Now

For now, I’ve decided to go with [Euronodes](https://euronodes.com/). The offer was inexpensive, and the company seemed stable based on what I found. From one of their posts, I understood that they have a small team of around eight core people, with the remaining data-center staff not on their payroll. That gave me a little more context about how they operate, although I’ll need to see how things work in practice.

My current guess is that this server should be enough to run around four or five small Node.js applications, with those applications sharing a database server. That’s only an estimate, of course. How much the server can handle will depend on what the applications do and how much traffic they get, so I’ll have to see how it performs once everything is running.

For now, I’m sticking with Euronodes and keeping the setup simple. If a project grows beyond what this server can comfortably handle, I can look at upgrading or moving it elsewhere. In a later post, I’ll write about how the setup went and share my user experience so far.
